# iOS 风格 3D 玻璃分流图标

**已发布完整 256px 透明 PNG，共 84 个按原配置名称导出的文件，涵盖 59 个独立图案。** 512px、原图与总览正在继续上传，尚未完成。

覆盖原配置的全部 81 个策略分组，另含 DIRECT、REJECT、无可用节点。地区和自动、故障转移、手动、手动优先、负载均衡子组均已包含。没有修改或接入分流配置。
